# API 索引

本文件是轻量 API 索引入口。真实接口以 `src/lib/services/` 和调用方为准。

## 1. 搜索位置

1. `api-catalog.json`
2. `src/lib/services/`
3. `src/app/api/`
4. 页面或 Hook 中的接口调用方。
4. 历史同类需求实现。

## 2. 使用原则

1. 请求必须走项目统一 request 层。
2. 不绕过已有 service 封装直接请求。
3. 错误处理、权限处理和 loading 状态需符合现有模式。
4. 新增接口封装应与同目录风格保持一致。
5. 涉及核心 request 封装属于核心模块变更，需明确标注。

## 3. Codex 执行方式

1. 先搜索同业务域 service。
2. 读取已有接口命名、参数、返回结构。
3. 复用现有错误处理和数据转换方式。
4. 新增接口时补充调用方验证。
