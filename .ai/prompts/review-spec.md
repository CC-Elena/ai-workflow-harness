# Prompt: 审查 Spec

## 目标

检查 Spec 是否足以支撑任务拆解、代码实现和验收。

## 检查项

1. 背景和目标是否清晰。
2. 范围是否明确，是否说明不做什么。
3. 用户场景是否覆盖核心路径。
4. 功能要求是否可执行。
5. 页面、组件、Hook、API 影响是否明确。
6. 权限、异常、空态、加载态是否覆盖。
7. 工程约束是否指向对应 Skills。
8. 验收标准是否可验证。
9. 是否存在阻塞实现的待确认问题。

## 输出格式

```text
结论：通过 / 需补充 / 不通过

主要问题：
1.
2.

建议补充：
1.
2.

是否可以进入 Planner：是 / 否
```
