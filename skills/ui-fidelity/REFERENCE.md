## 校验维度详解

### 📐 布局间距（权重 25%）

**检查要点**：
- 元素位置（左对齐、居中、右对齐）
- 容器宽高
- padding/margin 值
- Flex/Grid 布局方向

**常见问题**：
- 使用硬编码数值而非设计 token
- 未考虑内容动态变化

**评分标准**：
- **95%+**：间距误差 ≤ 2px
- **80-94%**：间距误差 ≤ 8px
- **<80%**：间距误差 > 8px 或布局错误

---

### 🎨 颜色主题（权重 20%）

**检查要点**：
- 主题色一致性
- 文字颜色层级
- 背景色
- 边框颜色
- 阴影

**常见问题**：
- 使用硬编码色值（如 `#333`）
- 未使用 `globals.css` 变量

**评分标准**：
- **95%+**：完全使用设计 token
- **80-94%**：色值接近但未使用变量
- **<80%**：色值明显偏差

---

### ✍️ 字体文本（权重 15%）

**检查要点**：
- 字号
- 字重（font-weight）
- 行高（line-height）
- 对齐方式
- 文字颜色

**常见问题**：
- 使用默认行高
- 字重不匹配

**评分标准**：
- **95%+**：所有文本属性匹配
- **80-94%**：字号正确，行高或字重有偏差
- **<80%**：字号错误

---

### 🖼️ 图标图片（权重 15%）

**检查要点**：
- 图标尺寸
- 图标颜色
- 图片比例
- 圆角

**常见问题**：
- 图标尺寸不统一
- 使用错误的图标

**评分标准**：
- **95%+**：尺寸、颜色完全匹配
- **80-94%**：尺寸偏差 ≤ 4px
- **<80%**：图标错误或尺寸偏差 > 4px

---

### 🔲 组件样式（权重 15%）

**检查要点**：
- 按钮样式（variant、size）
- 输入框样式
- 表格样式
- 卡片样式
- 弹窗样式

**常见问题**：
- 未使用项目基础组件
- 覆盖了组件默认样式

**评分标准**：
- **95%+**：完全使用基础组件
- **80-94%**：使用基础组件但有轻微定制
- **<80%**：自定义实现或样式偏差大

---

### 🎭 交互状态（权重 10%）

**检查要点**：
- 默认态
- Hover 态
- Active 态
- Focus 态
- Disabled 态

**常见问题**：
- 缺少 Hover 效果
- Disabled 态不明显

**评分标准**：
- **95%+**：所有状态完整实现
- **80-94%**：主要状态正确，次要状态有偏差
- **<80%**：缺少关键状态

---
