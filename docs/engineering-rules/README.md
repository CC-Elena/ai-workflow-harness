# 工程规范入口

本目录作为 AI 工作流的工程规范入口。

当前阶段不重复维护一套完整规范，而是引用已有 Skills 和项目规则：

1. 全局项目规范：`skills/project/SKILL.md`
2. 前端开发规范：`skills/frontend-dev/SKILL.md`
3. 组件复用规范：`skills/component-reuse/SKILL.md`
4. 测试规范：`skills/test/SKILL.md`
5. UI 还原规范：`skills/ui-fidelity/SKILL.md`
6. 自动规则沉淀：`skills/auto-rules/RULES.md`

如果后续出现跨 Skill 的统一工程规范，可在本目录补充专题文档。
