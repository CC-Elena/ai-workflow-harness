# PRD: Harness 基础设施强化

## 1. 背景

在具体业务需求进入前，项目需要先完善底座能力：CI、结构门禁、失败路径样本、接入文档和工作台浏览体验。

## 2. 目标

按优先级完成：

1. 新增 GitHub Actions CI。
2. 增强 `harness:check`。
3. 补齐失败路径和 RCA 样本。
4. 新增 Quick Start 与迁移验收清单。
5. 增强 `/files` 工作台资产浏览体验。

## 3. 非目标

1. 不引入 Agent Runtime。
2. 不引入数据库或后端服务。
3. 不改变现有业务功能边界。
4. 不覆盖用户已有文档修改。
