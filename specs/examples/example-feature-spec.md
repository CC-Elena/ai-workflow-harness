# Feature Spec: coupon-batch-send

## 1. 基本信息

- 需求名称：优惠券批量发放
- 需求来源：示例
- 负责人：待定
- 创建日期：2026-05-02
- 状态：Draft

## 2. 背景与目标

运营需要对一批用户发放指定优惠券。当前只能单个用户处理，效率低且容易遗漏。本需求希望支持批量导入用户并创建发券任务。

## 3. 范围

### 3.1 本次包含

1. 新增批量发券入口。
2. 支持导入用户 ID 列表。
3. 支持发放前校验优惠券库存。
4. 支持展示失败用户和失败原因。

### 3.2 本次不包含

1. 不支持复杂人群圈选。
2. 不支持自动定时发放。
3. 不改造已有优惠券创建流程。

## 4. 用户场景

| 场景 | 用户行为 | 期望结果 |
|------|----------|----------|
| 批量导入 | 运营上传用户 ID 文件 | 系统展示导入结果 |
| 库存不足 | 运营提交超过库存的发券任务 | 系统提示库存不足，禁止提交 |
| 部分失败 | 部分用户不满足发券条件 | 系统展示失败原因并支持导出 |

## 5. 功能要求

| 编号 | 功能点 | 说明 | 优先级 |
|------|--------|------|--------|
| F1 | 入口展示 | 在优惠券管理页新增批量发放入口 | P0 |
| F2 | 用户导入 | 支持上传 CSV 或文本格式用户 ID | P0 |
| F3 | 库存校验 | 提交前校验可用库存 | P0 |
| F4 | 失败展示 | 展示失败用户和失败原因 | P1 |

## 7. 数据与接口

| 接口或数据源 | 请求/输入 | 响应/输出 | 约束 |
|--------------|-----------|-----------|------|
| 批量发券校验 | 优惠券 ID、用户 ID 列表 | 可发放数量、失败用户 | 必须走统一 request 层 |
| 创建发券任务 | 优惠券 ID、用户 ID 列表 | 任务 ID | 失败需展示明确原因 |

## 8. 权限与异常场景

| 场景 | 处理方式 |
|------|----------|
| 无权限 | 隐藏入口或展示无权限提示 |
| 接口失败 | 展示错误提示，保留用户输入 |
| 空数据 | 禁止提交并提示导入用户 |
| 加载中 | 提交按钮 loading，避免重复提交 |
