# Feature Spec: asset-catalog-evaluation-filter

## 1. 基本信息

- 需求名称：仓库资产检索支持 Evaluation 和 Skill 分类
- 需求来源：真实低风险试点 P1
- 负责人：Codex
- 创建日期：2026-05-03
- 状态：Reviewed

## 2. 背景与目标

当前首页资产检索只覆盖 Workflow、Template、Context、Spec 四类资产，无法清晰承载执行评估和 Skill 维护类资产。

本需求目标是在不引入文件扫描、后端接口或独立平台的前提下，扩展静态资产目录，让用户能通过分类筛选快速找到 Evaluation 和 Skill 相关资产。

## 3. 范围

### 3.1 本次包含

1. 扩展资产分类类型。
2. 增加 Evaluation 和 Skill 筛选按钮。
3. 增加评估类和 Skill 类资产条目。
4. 运行构建验证并记录结果。

### 3.2 本次不包含

1. 不开发自动文件扫描。
2. 不接入数据库或后端接口。
3. 不修改 Run Record 草稿字段。
4. 不重设计首页布局。

## 4. 用户场景

| 场景 | 用户行为 | 期望结果 |
|------|----------|----------|
| 查找验证记录模板 | 点击 Evaluation 分类 | 能看到 `.ai/templates/verification-record-template.md` |
| 查找 Skill 路由 | 点击 Skill 分类 | 能看到 `.ai/context/skill-routing.md` 和 `skills/workflow-assets/SKILL.md` |
| 搜索试点资产 | 输入 pilot 或 试点 | 能看到真实试点候选清单 |

## 5. 功能要求

| 编号 | 功能点 | 说明 | 优先级 |
|------|--------|------|--------|
| F1 | 新增分类类型 | `Asset.category` 支持 `Evaluation` 和 `Skill` | P0 |
| F2 | 更新筛选按钮 | 分类按钮包含新类型 | P0 |
| F3 | 更新资产列表 | 增加验证、评估、Skill 相关资产 | P0 |
| F4 | 保持搜索行为 | 搜索逻辑不回退 | P1 |

## 6. 页面与组件影响

| 类型 | 名称或路径 | 变更说明 |
|------|------------|----------|
| 页面 | `src/components/views/workflow-workspace.tsx` | 扩展 Asset 分类和静态资产数据 |
| 样式 | `src/app/globals.css` | 必要时保证新增分类按钮在移动端不溢出 |

## 7. 数据与接口

| 接口或数据源 | 请求/输入 | 响应/输出 | 约束 |
|--------------|-----------|-----------|------|
| 静态资产数组 | 页面内常量 | 资产列表 | 不新增接口 |

## 8. 权限与异常场景

| 场景 | 处理方式 |
|------|----------|
| 新分类无匹配资产 | 显示空列表计数为 0，不报错 |
| 搜索和分类组合无结果 | 保持现有空列表行为 |

## 9. 设计与交互约束

1. 复用现有 segmented button 样式。
2. 不新增说明型大段文案。
3. 移动端按钮允许换行。

## 10. 工程约束

1. 不新增依赖。
2. 不改变 localStorage key。
3. 不改变 Run Record 草稿数据结构。

## 11. 验收标准

| 编号 | 验收项 | 验收方式 |
|------|--------|----------|
| A1 | `Evaluation` 和 `Skill` 分类按钮存在 | 页面检查 |
| A2 | 资产列表包含新增工作流资产 | 页面检查 |
| A3 | 搜索和分类组合仍可过滤资产 | 手工检查 |
| A4 | `npm run build` 通过 | 命令验证 |

## 12. 风险与待确认问题

| 类型 | 说明 | 处理方式 |
|------|------|----------|
| 风险 | 静态资产列表需要人工维护 | 后续通过 workflow-assets Skill 维护 |
