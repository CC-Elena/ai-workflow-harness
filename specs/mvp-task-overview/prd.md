# PRD：首页展示 MVP 任务完成概览

## 1. 背景

开发计划和试点记录已经完成，但首页仍只展示阶段卡片和资产检索。用户需要一个更直接的区域确认 MVP 任务完成情况、试点数量和最近完成项。

## 2. 目标

在首页增加紧凑的 MVP 任务完成概览，让使用者无需打开文档也能判断当前工作流是否收口。

## 3. 功能需求

1. 展示开发计划任务完成数量。
2. 展示真实试点完成数量。
3. 展示剩余候选数量。
4. 展示最近完成试点。
5. 阶段卡片状态与已完成文档状态保持一致。

## 4. 非目标

1. 不开发自动统计。
2. 不接入文件扫描。
3. 不接入后端接口。
4. 不开发复杂看板。

## 5. 验收标准

1. 首页展示 MVP 完成概览。
2. 概览数值与试点文档一致。
3. 工作流阶段不再显示真实试点仍 pending。
4. `npm run lint` 和 `npm run build` 通过。
