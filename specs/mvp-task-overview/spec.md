# Feature Spec: mvp-task-overview

## 1. 基本信息

- 需求名称：首页展示 MVP 任务完成概览
- 需求来源：真实低风险试点 P3
- 负责人：Codex
- 创建日期：2026-05-03
- 状态：Reviewed

## 2. 背景与目标

当前仓库已完成 MVP 工作流资产和三个真实低风险试点，需要在首页用静态概览展示完成状态，减少文档与页面认知不一致。

## 3. 范围

### 3.1 本次包含

1. 增加 MVP 任务完成概览区。
2. 更新阶段卡片状态为完成。
3. 更新 hero 提示文案。
4. 保持现有资产检索和草稿表单行为。

### 3.2 本次不包含

1. 不自动读取 Markdown。
2. 不开发统计服务。
3. 不新增依赖。

## 4. 用户场景

| 场景 | 用户行为 | 期望结果 |
|------|----------|----------|
| 查看 MVP 状态 | 打开首页 | 看到任务、试点和最近完成项 |
| 核对阶段状态 | 查看工作流阶段 | 所有阶段显示 Ready |

## 5. 功能要求

| 编号 | 功能点 | 说明 | 优先级 |
|------|--------|------|--------|
| F1 | MVP 概览数据 | 页面内静态常量承载 | P0 |
| F2 | 概览 UI | 四项紧凑指标 | P0 |
| F3 | 阶段状态同步 | Planner、Executor、Verify 改为 Ready | P0 |

## 6. 页面与组件影响

| 类型 | 名称或路径 | 变更说明 |
|------|------------|----------|
| 页面 | `app/workflow-workspace.tsx` | 增加概览数据和区块 |
| 样式 | `app/globals.css` | 增加响应式概览样式 |

## 7. 数据与接口

| 接口或数据源 | 请求/输入 | 响应/输出 | 约束 |
|--------------|-----------|-----------|------|
| 静态常量 | 无 | MVP 概览 | 后续自动统计另开需求 |

## 8. 验收标准

| 编号 | 验收项 | 验收方式 |
|------|--------|----------|
| A1 | 概览区展示 4 个指标 | 页面检查 |
| A2 | 阶段状态均为 Ready | 页面检查 |
| A3 | 桌面和移动端不溢出 | 截图检查 |
| A4 | lint 和 build 通过 | 命令验证 |

## 9. 风险

| 类型 | 说明 | 处理方式 |
|------|------|----------|
| 风险 | 静态数值后续可能过期 | 通过 workflow-assets Skill 维护 |
