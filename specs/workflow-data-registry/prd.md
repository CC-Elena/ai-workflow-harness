# PRD：首页工作流数据集中维护

## 1. 背景

首页展示的资产列表、MVP 任务数和试点数量原本集中写在页面组件中。每次新增资产或任务时，需要同时修改页面常量和文档，容易出现数字过期。

## 2. 目标

将首页工作流展示数据抽到独立模块，并让 MVP 指标从数据数组计算出来，减少重复维护。

## 3. 功能需求

1. 新增前端工作流数据模块。
2. 资产、阶段、任务、试点数据从模块导出。
3. 首页从数据模块导入并渲染。
4. `Development plan` 和 `Real pilots` 指标由数组长度和完成数计算。
5. `Latest pilot` 使用最近任务 ID 和标题。

## 4. 非目标

1. 不读取 Markdown 文件。
2. 不实现自动文件扫描。
3. 不新增后端接口。
4. 不引入数据库或脚本平台。

## 5. 验收标准

1. 首页显示 `36/36`、`3/3`、`17 files`。
2. 首页资产筛选仍可用。
3. `npm run lint`、`npm run typecheck`、`npm run build` 通过。
4. 桌面和移动端无横向溢出。
