# PRD: 通用 Coding Agent 前端开发 Harness 调研报告

## 1. 背景

团队希望不绑定单一 Coding Agent，系统了解行业 Harness、SDD 和 Agent workflow 的做法，并形成适用于前端需求交付的团队工作方式。

## 2. 目标

1. 梳理 Claude Code、Codex、Cursor、Windsurf、Trae、Qwen Code、通义灵码和阿里 SDD / Harness Engineering 的做法。
2. 总结让 AI 产出代码更贴近代码库风格、可审计、可进化的方法。
3. 产出团队可复用的通用前端 AI 工作方式和配套模板。

## 3. 非目标

1. 不绑定 Codex 或任一单一 Agent。
2. 不实现新的 Agent Runtime。
3. 不修改当前应用代码。
4. 不扩展到后端、发布和生产运维。
