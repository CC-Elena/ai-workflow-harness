# PRD：Run Record 草稿增加验证摘要字段

## 1. 背景

首页已有 Run Record 草稿表单，可以保存需求名称、负责人、状态和执行摘要。随着验证协议完善，使用者需要在保存草稿时同步记录验证摘要，减少执行结果和验证结果分散的问题。

## 2. 目标

让用户可以在首页 Run Record 草稿中填写并保存“验证摘要”，用于记录构建、Lint、截图或跳过项的简短结论。

## 3. 功能需求

1. Run Record 草稿数据增加 `verificationSummary` 字段。
2. 表单增加“验证摘要”输入区。
3. 保存草稿时将验证摘要写入原有 localStorage。
4. 读取旧草稿时兼容缺少 `verificationSummary` 的数据。

## 4. 非目标

1. 不新增后端接口。
2. 不修改 localStorage key。
3. 不开发完整验证记录编辑器。

## 5. 验收标准

1. 页面展示“验证摘要”字段。
2. 保存后刷新页面，验证摘要仍保留。
3. 旧草稿缺少该字段时页面不报错。
4. `npm run lint` 和 `npm run build` 通过。
