# Feature Spec: run-record-verification-summary

## 1. 基本信息

- 需求名称：Run Record 草稿增加验证摘要字段
- 需求来源：真实低风险试点 P2
- 负责人：Codex
- 创建日期：2026-05-03
- 状态：Reviewed

## 2. 背景与目标

当前 Run Record 草稿只记录执行摘要，无法直接记录验证结论。本需求在不改变存储 key 和不接入后端的前提下，增加验证摘要字段。

## 3. 范围

### 3.1 本次包含

1. 扩展 `RunDraft` 数据结构。
2. 增加验证摘要输入区。
3. 保存和读取 localStorage 时支持新字段。
4. 兼容旧草稿。

### 3.2 本次不包含

1. 不开发验证记录列表。
2. 不自动解析构建日志。
3. 不新增 API 或数据库。

## 4. 用户场景

| 场景 | 用户行为 | 期望结果 |
|------|----------|----------|
| 记录验证结论 | 填写验证摘要并保存 | 刷新后内容仍保留 |
| 读取旧草稿 | 浏览器已有旧 localStorage | 页面正常显示默认验证摘要 |

## 5. 功能要求

| 编号 | 功能点 | 说明 | 优先级 |
|------|--------|------|--------|
| F1 | 数据结构扩展 | `RunDraft` 增加 `verificationSummary` | P0 |
| F2 | 表单字段 | 新增“验证摘要” textarea | P0 |
| F3 | 旧数据兼容 | localStorage 读取时补默认值 | P0 |

## 6. 页面与组件影响

| 类型 | 名称或路径 | 变更说明 |
|------|------------|----------|
| 页面 | `app/workflow-workspace.tsx` | 扩展草稿数据和表单 |

## 7. 数据与接口

| 接口或数据源 | 请求/输入 | 响应/输出 | 约束 |
|--------------|-----------|-----------|------|
| localStorage | `ai-workflow-run-draft` | RunDraft JSON | key 不变 |

## 8. 验收标准

| 编号 | 验收项 | 验收方式 |
|------|--------|----------|
| A1 | 验证摘要字段存在 | 页面检查 |

| A3 | 旧草稿兼容 | 浏览器脚本检查 |
| A4 | lint 和 build 通过 | 命令验证 |

| 类型 | 说明 | 处理方式 |
|------|------|----------|
